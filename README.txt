link5_pkg.vhd
เป็น package ที่กำหนดว่าข้อมูลหนึ่งเฟรมหน้าตาอย่างไร ทั้งสองฝั่งใช้ไฟล์เดียวกัน เพื่อให้ฟอร์แมตตรงกันเสมอ

กำหนดค่าคงที่: เฟรมยาว 5 ไบต์ (FRAME_LEN) และ opcode สูงสุดที่ยอมรับ 13 (LAST_OPCODE)
กำหนดเรคคอร์ดฟิลด์ fields_t: opcode(4), mon_p(2), lvl_p(6), hp_p(8), mon_e(2), lvl_e(6), hp_e(8), cursor(2), pad(2)
pack() แปลงฟิลด์เป็น 5 ไบต์ (ส่ง MSB ก่อน) และ unpack() แปลงกลับ



link_master.vhd (FPGA2: ตัวส่งเฟรม)
ส่งสถานะเกมทั้งหมดไป FPGA1 วนซ้ำทุกเฟรม และเก็บคำตอบที่ FPGA1 ส่งกลับ

ทุก 2^19 clock (ประมาณ 10.5 ms) จะถ่ายสถานะเกมเก็บไว้ 1 ชุด แล้วส่งเป็นเฟรม 5 ไบต์
ลำดับต่อเฟรม: ดึง CS ลง → รอ 63 clock → ส่งทีละไบต์ผ่าน spi_master → รอ 63 clock → ปล่อย CS
ไบต์แรกของเฟรมคือคำตอบจาก FPGA1: เช็ค 5 บิตแรกว่าเท่ากับ REPLY_TAG (#pleng 10101) ถ้าตรงจึงรับ colour1 กับ LV และตั้ง reply_ok = 1 ถ้าไม่ตรงจะคงค่าเดิมไว้
ส่งออกสัญญาณ rx_colour1, rx_lv, rx_new, reply_ok, frame_sent ให้ game logic ใช้



link_slave.vhd (FPGA1: ตัวรับเฟรม)
รับเฟรมจาก FPGA2 ตรวจความถูกต้อง แล้วเก็บเป็นสถานะเกมปัจจุบัน พร้อมส่งคำตอบสีกลับ

ต่อกับ spi_slave เก็บไบต์ที่รับมาลงบัฟเฟอร์ตามลำดับ
เมื่อ CS ขึ้น (จบเฟรม) จะเช็ค 3 อย่าง: ยาว 5 ไบต์พอดี, opcode ≤ 13, pad = 00 ถ้าผ่านจะเขียนทุกฟิลด์พร้อมกันทีเดียว (cur_f) ถ้าไม่ผ่านจะทิ้งเฟรมและค่าเดิมยังอยู่
ไบต์ตอบกลับ = REPLY_TAG & colour1 & LV ส่งในไบต์แรกของเฟรมเสมอ ไบต์ที่เหลือตอบ 00
มี watchdog: link_up เป็น 1 เมื่อได้เฟรมดีครบ และกลับเป็น 0 ถ้านานราว 84 ms ไม่มีเฟรมดี
ส่งออก rx_new (พัลส์เมื่อเฟรมดี), bad_frame (พัลส์เมื่อทิ้งเฟรม), link_up




spi_master.vhd (FPGA2: ส่งทีละไบต์)
SPI master ระดับไบต์ mode 0 ส่ง MSB ก่อน

SCLK = clk / (2 × CLK_DIV) ค่าเริ่มต้น 25 ได้ 1 MHz จาก 50 MHz
รับคำสั่ง start 1 พัลส์ พร้อมไบต์ที่จะส่ง แล้วขยับ 8 บิต ส่ง MOSI ที่ขอบตก อ่าน MISO ที่ขอบขึ้น เมื่อครบจะพัลส์ done และให้ไบต์ที่อ่านได้ใน rx_data
ไม่ขับขา CS เอง ชั้นบน (link_master) เป็นคนควบคุม CS และเวลาหน่วงก่อน/หลัง
มี synchronizer 2 ขั้นที่ขา MISO



spi_slave.vhd (FPGA1: รับทีละไบต์)
SPI slave ระดับไบต์ ใช้ clock ของบอร์ด (50 MHz) สุ่มอ่านสัญญาณ SPI แทนการใช้ SCLK เป็น clock

ผ่านสัญญาณ SCLK, MOSI, CS เข้า synchronizer แล้วตรวจขอบขึ้นและขอบตกเอง
ขอบขึ้นของ SCLK: อ่านบิตจาก MOSI ครบ 8 บิตก็ส่งไบต์ออก (rx_byte, rx_valid, rx_idx)
ขอบตก: ขยับบิตถัดไปออก MISO
ตอน CS สูง จะเตรียมไบต์แรกของ tx_data ไว้ล่วงหน้า เพื่อให้บิตแรกพร้อมก่อนมีสัญญาณ SCLK
พอ CS ขึ้นจะส่ง frame_end พร้อมจำนวนไบต์ที่รับได้ (frame_len) ให้ชั้นบนตรวจ




spi_module.vhd (FPGA1: ตัวห่อให้ top)
เป็นตัวที่ top ของ FPGA1 เรียกใช้ ซ่อนรายละเอียดของลิงก์ไว้ด้านใน

รับ analysis_result (colour1 + LV จากวงจรนับสี) ส่งให้ link_slave ตอบกลับ FPGA2
รับสถานะเกมจาก link_slave แล้วรวมเป็นบัส control 38 บิต ตามลำดับ opcode, mon_p, lvl_p, hp_p, mon_e, lvl_e, hp_e, cursor ให้ส่วนแสดงผลใช้
rx_new, bad_frame, link_up ต่อเป็น open จึงไม่ถูกส่งออก
