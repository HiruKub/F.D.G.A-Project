================================================================================
          FPGA CAMERA-BASED MONSTER BATTLE SYSTEM SPECIFICATION
                       (EDGE Spartan-7 Dual Board)
================================================================================

1. การแบ่งหน้าที่ของบอร์ด (DUAL-BOARD SYSTEM ARCHITECTURE)
--------------------------------------------------------------------------------
[ FPGA 1: Graphics, Video & All-in-One VGA Hub ]
- ต่อกล้องถ่ายภาพความละเอียด 120p (RGB332)
- ต่อจอแสดงผล VGA (640x480 @ 60Hz) แสดงกราฟิกและองค์ประกอบทั้งหมดบนจอเดียว (All-in-One VGA):
  * หน้า Title / Start Screen (หน้าแรกของเกม)
  * ฉากหลังสดจากกล้อง (Live Feed) / ภาพนิ่งแช่ค้าง (Snapshot Background)
  * ตัวละครมอนสเตอร์ทั้ง 2 ฝั่ง (Sprite 32x32 ขยาย 2x เป็น 64x64, รองรับ Flip หันหลังหนี)
  * HUD ด้านบน: หลอดเลือด HP, ตัวเลข Level, ชื่อธาตุของทั้งผู้เล่นและศัตรู
  * เมนูด้านล่าง: ตัวเลือกคำสั่ง (ATK, CAPT, RUN), เมนูสกิล (1, 2) และกล่องข้อความบรรยายการต่อสู้
- ประมวลผล Color Histogram ค้นหาสีเด่นสูงสุด 2 อันดับแรก (Color 1, Color 2) แล้วส่งต่อให้ FPGA 2

[ FPGA 2: Game Logic Engine & Controller ]
- รับสัญญาณอินพุตจากปุ่มกด 3 ปุ่ม:
  * BTN1: เลื่อนขึ้น / ก่อนหน้า (UP / PREV)
  * BTN2: เลื่อนลง / ถัดไป (DOWN / NEXT)
  * BTN3: ยืนยัน / เลือก / ดำเนินการ (CONFIRM / EXECUTE)
- ทำงานด้วย Finite State Machine (FSM) ประมวลผลกฎ กติกา และสถานะการต่อสู้ทั้งหมด
- จัดเก็บข้อมูลคลังมอนสเตอร์ของผู้เล่น (Inventory & Level Persistence)
- คำนวณความเสียหายตามสเกลเลเวล (Level-Scaled Damage Calculator):
  * Base DMG = (Level / 2) + 2
  * ชนะธาตุ (Advantage): Base DMG x 2
  * เสมอธาตุ (Neutral): Base DMG x 1
  * แพ้ธาตุ (Disadvantage): Base DMG / 2 (ขั้นต่ำ 1)
- ส่งข้อมูลสเตตัส, เคอร์เซอร์ และคำสั่งแอนิเมชันกลับไปควบคุมการวาดกราฟิกบน FPGA 1


2. กฎและลำดับขั้นตอนการเล่นเกม (GAMEPLAY FLOW & RULES)
--------------------------------------------------------------------------------
0. หน้าแรก (Title Screen):
   - เปิดเครื่องหรือรีเซ็ตระบบ จะเข้าสู่หน้าแรก "MONSTER BATTLE"
   - ผู้เล่นกดปุ่ม BTN3 เพื่อเริ่มต้นเข้าสู่เกม

1. เลือกมอนสเตอร์ในคลัง (Monster Selection):
   - มีมอนสเตอร์ให้เลือกครบทั้ง 3 ธาตุ: ไฟ (Fire), พืช (Plant), น้ำ (Water)
   - เริ่มต้นเกมทุกตัวมีเลเวล 1 (HP สูงสุด = (1 x 2) + 16 = 18)
   - ใช้ BTN1 / BTN2 เลื่อนเลือกตัว และกด BTN3 เพื่อยืนยันเข้าสู่ฉากสแกน

2. ถ่ายภาพตรวจจับศัตรู (Camera Enemy Scanning):
   - หันกล้องไปยังวัตถุเป้าหมาย และกดถ่ายภาพ
   - FPGA 1 ประมวลผลสีเด่นอันดับ 1 และ 2 ส่งมาให้ FPGA 2

3. การกำเนิดศัตรู (Enemy Spawning Logic):
   - ชนิดมอนสเตอร์: พิจารณาจากสีที่มีความถี่มากที่สุดอันดับที่ 1 (แดง = ไฟ, เขียว = พืช, น้ำเงิน = น้ำ)
   - เลเวลของศัตรู: พิจารณาจากบิตสุดท้าย (LSB, bit 0) ของสีอันดับที่ 2
     * ถ้าบิตสุดท้ายเป็น '0' -> เลเวลศัตรู = เลเวลมอนสเตอร์ของเรา
     * ถ้าบิตสุดท้ายเป็น '1' -> เลเวลศัตรู = เลเวลมอนสเตอร์ของเรา + 5

4. สูตรการคำนวณหลอดเลือด (Level-Scaled HP Formula):
   - Max HP = (Level x 2) + 16 (ใช้สูตรเดียวกันทั้งผู้เล่นและศัตรู)
     * Level 1: Max HP = 18
     * Level 6: Max HP = 28

5. เมนูคำสั่งการต่อสู้ (Action Menu):
   5.1 ถ้าเลือก ATK (โจมตี):
       - เข้าสู่เมนูย่อยเลือกได้ 2 สกิล:
         * Skill 1 (Elemental Strike): ท่าโจมตีประจำธาตุ คิดตามสเกลเลเวล
           - ชนะธาตุ: Base DMG x 2 (เช่น Lv 1 = 4, Lv 6 = 10)
           - เสมอธาตุ: Base DMG x 1 (เช่น Lv 1 = 2, Lv 6 = 5)
           - แพ้ธาตุ: Base DMG / 2 (เช่น Lv 1 = 1, Lv 6 = 2)
         * Skill 2 (Normal Tackle): ท่าโจมตีกายภาพ ดาเมจเท่ากับ Base DMG คงที่ไม่คิดผลของธาตุ
       - ผู้เล่นโจมตี -> หักลบ HP ศัตรู:
         * ถ้า HP ศัตรูหมด (<= 0) -> ศัตรูพ่ายแพ้ (Victory!) -> กด BTN3 กลับไปหน้าเลือกมอนสเตอร์
         * ถ้าศัตรูยังไม่ตาย -> ศัตรูโจมตีสวนกลับ 1 ครั้ง (ใช้ Elemental Strike คำนวณตามเลเวลศัตรู)
           - ถ้า HP ผู้เล่นหมด (<= 0) -> ผู้เล่นพ่ายแพ้ (Defeat!) -> กด BTN3 กลับไปหน้าเลือกมอนสเตอร์
           - ถ้าผู้เล่นยังไม่ตาย -> กลับสู่หน้า Action Menu รอบถัดไป
   
   5.2 ถ้าเลือก CAPT (จับมอนสเตอร์):
       - ตรวจสอบเลือดปัจจุบันของศัตรู:
         * หาก HP ศัตรูเหลือ <= 25% ของ Max HP (หรือ <= 4) -> จับสำเร็จ! นำเลเวลของศัตรูตัวนั้นมาบันทึกแทนเลเวลตัวเดิมในคลังของเราทันที -> จบการต่อสู้ กลับสู่หน้าเลือกมอนสเตอร์
         * หาก HP ศัตรูเหลือ > 25% -> จับล้มเหลว! โดนศัตรูโจมตีสวนฟรี 1 ครั้ง (ถ้าผู้เล่นยังไม่ตาย จะกลับสู่หน้า Action Menu)

   5.3 ถ้าเลือก RUN (หนี):
       - ผู้เล่นหลบหนีสำเร็จ 100% (สไปรท์ผู้เล่นหันหลังวิ่งหนี) -> กด BTN3 เพื่อกลับสู่หน้าเลือกมอนสเตอร์ทันที
