              VGA SCREEN LAYOUT SPECIFICATION (640x480 @ 60Hz)
             FPGA Camera-Based Monster Battle Project

1. ภาพรวมพิกัดมาตรฐานบนหน้าจอ (GLOBAL COORDINATE MAP)
--------------------------------------------------------------------------------
- Resolution: 640 x 480 พิกเซล (X: 0..639, Y: 0..479)
- Top HUD Zone (ข้อมูลผู้เล่น/ศัตรู)  : Y = 10  ถึง 60
- Center Sprite Zone (ตำแหน่งตัวละคร): Y = 180 ถึง 320 (ขยาย Sprite 2x เป็น 64x64 px)
- Bottom Menu Zone (กล่องคำสั่ง/ข้อความ): Y = 370 ถึง 460 (X: 20 ถึง 620)

ค่าพิกัดคงที่สำหรับนำไปประกาศใน VHDL Constants:
  constant P_HP_X_START : integer := 20;   -- จุดเริ่มหลอด HP ฝั่งผู้เล่น
  constant P_HP_Y_START : integer := 50;
  constant E_HP_X_START : integer := 420;  -- จุดเริ่มหลอด HP ฝั่งศัตรู
  constant E_HP_Y_START : integer := 50;
  constant HP_BAR_WIDTH : integer := 200;  -- ความยาวหลอด HP สูงสุด
  
  constant PLAYER_X     : integer := 100;  -- พิกัดตัวละครฝั่งซ้าย (ตัวเรา)
  constant PLAYER_Y     : integer := 200;
  constant ENEMY_X      : integer := 476;  -- พิกัดตัวละครฝั่งขวา (ศัตรู)
  constant ENEMY_Y      : integer := 200;

  constant MENU_BOX_X1  : integer := 20;   -- ขอบซ้ายกล่องเมนู
  constant MENU_BOX_X2  : integer := 620;  -- ขอบขวากล่องเมนู
  constant MENU_BOX_Y1  : integer := 370;  -- ขอบบนกล่องเมนู
  constant MENU_BOX_Y2  : integer := 460;  -- ขอบล่างกล่องเมนู

3. สรุปข้อแนะนำการลงโค้ด VHDL (TECHNICAL NOTES)
--------------------------------------------------------------------------------
1. การสร้างกรอบทั้งหมดใช้ Combinational Logic (Comparators) ไม่เสีย BRAM
2. การทำ Horizontal Flip ในฉาก ST_RUN_EVADE:
   x_rom <= not x_rel when (is_flipped = '1') else x_rel;
3. สีพื้นหลังของฉากการต่อสู้ (Scenes 3-8) ดึงภาพแช่ค้าง (Snapshot) จาก Camera BRAM
